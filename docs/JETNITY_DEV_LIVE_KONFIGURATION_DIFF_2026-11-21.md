Korrektur: negativer Server-/CDN-Cache nur ca. 60 Sekunden, fehlgeschlagene Browser-Promises entfallen, genau ein automatischer Retry; keine neue kostenpflichtige Bildquelle. **Chrome-Pflicht:** neue Reise mit Berlin DE, Paris FR, Bangkok TH; Ortsbild/Nachweis, Neuaufruf und unbekannter Ort (Atlas statt falschem Foto) prüfen, im Browser Network Status von `/api/travel-images` sichern.
